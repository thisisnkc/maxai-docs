---
title: "Rerank"
description: "Scores each text by relevance to a query using bge-reranker-v2-m3. This endpoint is not OpenAI-compatible; call it over plain HTTP."
api: "POST https://maxai.knowmax.in/tei/rerank"
---

## Authorizations

<ParamField header="Authorization" type="string" required>
Bearer authentication header of the form `Bearer <MAXAI_API_KEY>`.
</ParamField>

## Body

<ParamField body="query" type="string" required>
The search query.
</ParamField>

<ParamField body="texts" type="string[]" required>
Candidates to score. Maximum 8 per request and 8,192 tokens per text.
</ParamField>

<ParamField body="truncate" type="boolean" default="true">
Truncate texts over 8,192 tokens. With `false`, long texts return `422`.
</ParamField>

<ParamField body="return_text" type="boolean">
Include each text in its result.
</ParamField>

<ParamField body="raw_scores" type="boolean">
Return unbounded scores instead of scores between 0 and 1.
</ParamField>

## Response

<ResponseField name="[ ]" type="object[]">
Results sorted by `score`, highest first. `index` points into `texts`; `text` is present when `return_text` is set.
</ResponseField>

<RequestExample>
```python Python
import os
import requests

response = requests.post(
    "https://maxai.knowmax.in/tei/rerank",
    headers={"Authorization": f"Bearer {os.environ['MAXAI_API_KEY']}"},
    json={
        "query": "how do I reset my password?",
        "texts": [
            "Billing is handled under Account > Plans.",
            "To reset your password, open Settings > Security.",
        ],
    },
)

for result in response.json():
    print(result["index"], result["score"])
```
