## Services and base URLs

One API key works for every service. Each model has its own base URL. The SDK takes the **base URL**; curl takes the **full endpoint URL**.

| Service | Model | SDK base URL | OpenAI SDK |
| --- | --- | --- | --- |
| Chat | `km/maxai` | `https://maxai.knowmax.in/llm` | Yes |
| Chat, thinking | `km/maxai2` | `https://maxai.knowmax.in/llm2` | Yes |
| Embeddings | multilingual-e5-large | `https://maxai.knowmax.in/rag` | Yes |
| Embeddings | multilingual-e5-small | `https://maxai.knowmax.in/rag2` | Yes |
| Reranker | bge-reranker-v2-m3 | `https://maxai.knowmax.in/tei` | No, HTTP only |

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| <span className="method-badge method-post">POST</span> | [\{base\}/chat/completions](/api-reference/create-chat-completion) | Chat completion, normal or streaming |
| <span className="method-badge method-get">GET</span> | [\{base\}/models](/api-reference/list-models) | The model served on a chat base URL |
| <span className="method-badge method-post">POST</span> | [\{base\}/embeddings](/api-reference/create-embeddings) | Embedding vectors |
| <span className="method-badge method-post">POST</span> | [/tei/rerank](/api-reference/rerank) | Rerank texts against a query |
